974:     "current_page": 1, "last_page": 2, "per_page": 12, "total": 18
975:   },
976:   "categories": [ /* §8.2 */ ],
977:   "sizes": ["M", "L", "XL"],
978:   "filters": { "q": null, "kategori": null, "ukuran": null, "harga_min": null, "harga_max": null,
979:                "urut": "terbaru", "page": 1 },
980:   "error": null
981: }
982: ```

984: | Key | Aturan |
985: |---|---|
986: | `products` | selalu objek paginator (`data[]`), `per_page` 12; hasil kosong → `data: []`, `total: 0` |
987: | `categories` | bentuk §8.2 (termasuk `product_count`) |
988: | `sizes` | ukuran unik `product_variants.size` varian aktif dari produk aktif, urut ukuran baku (XS, S, M, L, XL, XXL, …; ukuran di luar daftar di belakang, urut abjad) |
989: | `filters` | selalu memuat seluruh key; nilai kosong `null`, `urut` bawaan `terbaru`, `page` integer hasil normalisasi; `ukuran` dikirim sebagai string koma yang sudah dinormalisasi |

994: `order_items.qty` pada pesanan berstatus ≠ `batal` (turun) lalu `id` naik; `rating` = `rating_avg`
995: turun, `rating_count` turun, `id` naik.

681: ### 5.14 Halaman error (404 / 403 / 419 / 500)
682: 
683: - Layout penuh: header + footer tetap tampil (kecuali 500 yang gagal render layout → versi minimal).
684: - Komposisi: kode status `font-display text-display text-brand`, judul `text-h2`, penjelasan `text-body text-ink-soft`, dua CTA: "Ke Beranda" (`primary`) dan "Hubungi Kami" (`secondary`).
685: - 419: "Sesi kamu berakhir. Muat ulang halaman lalu coba lagi." + tombol muat ulang.
686: - 403: tanpa membocorkan detail otorisasi. 500: pesan generik + kode referensi singkat, tanpa stack trace.

735: ## 7. Aturan Implementasi
736: 
737: 1. Token warna/spacing **wajib** masuk `tailwind.config.js` (`theme.extend`), bukan hex di JSX. Hex di luar config hanya untuk API JS yang menuntut string warna (§2.6 butir 2).
738: 2. Semua ikon: SVG inline 20px (`stroke-width: 1.5`), atau `lucide-react` bila ditambahkan.
739: 3. Gambar produk: rasio 1:1, `object-cover`, `loading="lazy"` kecuali hero (`eager` + `fetchpriority="high"`), wajib `alt`.
740: 4. Tidak ada `Lorem ipsum` — pakai copy Indonesia nyata atau data seeder.
741: 5. Setiap halaman wajib punya state **loading**, **empty**, **error** (§4.0). Error tampil **di dalam layout**, bukan halaman putih.
742: 6. Fokus keyboard terlihat di semua elemen interaktif (ring 2px `brand`, offset 2px — sudah global di `app.css`).
743: 7. Mobile: target sentuh ≥ 44×44px, tidak ada horizontal scroll pada 360px.
744: 8. Admin memakai token yang sama — jangan bikin sistem warna kedua.
745: 9. Komponen dipakai ulang dari `resources/js/Components/` — jangan menyalin kelas yang sama di dua halaman. API props: `docs/komponen.md`.
746: 10. Nilai token di JS hanya lewat kelas; bila butuh angka di JS (mis. lebar drawer untuk animasi), ambil dari konstanta yang sama dengan config, jangan duplikasi.
