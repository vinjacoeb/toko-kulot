BUKTI VERIFIKASI DoD §15.1 — migrate:fresh --seed
=================================================
Tanggal     : 2026-10-20 14:00 (UTC+07:00)
Mesin       : Windows 11 (Laragon), PHP 8.3.32, MySQL 8.0.30
Tujuan      : membuktikan migrasi + seeder utuh dari nol pada MySQL 8 (bukan SQLite),
              TANPA menyentuh database dev `toko-kulot` yang berisi data pemilik.

Cara isolasi
------------
1. mysql -u root -e "CREATE DATABASE IF NOT EXISTS toko_kulot_rilis_check CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
2. DB_DATABASE=toko_kulot_rilis_check php artisan migrate:fresh --seed --no-interaction
   (variabel lingkungan DB_DATABASE menimpa nilai .env untuk proses ini saja; file .env
    tidak dibuka, diubah, maupun ditampilkan oleh DevOps.)
3. Setelah bukti dikumpulkan: DROP DATABASE toko_kulot_rilis_check.

Kredensial: akun MySQL lokal tanpa sandi (bawaan Laragon) dipakai hanya untuk membuat dan
menghapus database uji di atas. Tidak ada rahasia yang ditulis atau dibaca dari .env.
