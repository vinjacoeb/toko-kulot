# Asumsi DevOps

1. Menggunakan Next.js App Router (TypeScript).
2. Database MySQL akan dibuat oleh pemilik (atau dicoba dibuat oleh agent jika memungkinkan tanpa akses root/password).
3. browser-use dan computer-use adalah alat/library yang akan diinstal melalui npm sesuai kebutuhan di kartu berikutnya.
